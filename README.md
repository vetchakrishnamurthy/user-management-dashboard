# User Management Dashboard

A simple and interactive User Management Dashboard built using React and Vite. This application allows users to manage user information through CRUD operations.

## Features

- Add new users
- View all users
- Edit existing user details
- Delete users
- Search users
- API integration

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
- REST API (JSONPlaceholder)

## API Used

[JSONPlaceholder](https://jsonplaceholder.typicode.com/users)

## Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd user-management-dashboard
```

**3. Install dependencies**

```bash
npm install

### Main Dependencies
- **React (^19.3.1)** – JavaScript library for building user interfaces.
- **React DOM (^19.3.1)** – Used to render React components in the browser.
- **Axios (^1.21.0)** – Used to make HTTP requests and communicate with REST APIs.

### Development Dependencies
- **Vite (^8.3.6)** – Frontend build tool and development server.
- **@vitejs/plugin-react (^6.1.2)** – Enables React support in Vite.
- **ESLint (^10.14.0)** – Identifies and reports JavaScript coding issues.
- **@eslint/js** – JavaScript ESLint configurations.
- **eslint-plugin-react-hooks** – Helps follow React Hooks rules.
- **eslint-plugin-react-refresh** – Supports React Fast Refresh.
- **globals** – Provides global variable definitions for ESLint.
- **@types/react** – React type definitions.
- **@types/react-dom** – React DOM type definitions.

**4. Start the development server**

```bash
npm run dev
```

## Note

This project uses JSONPlaceholder, a fake REST API for testing and practising CRUD operations. Changes are simulated and are not permanently stored on the server.
